# Tamil IPTV App

Free Tamil IPTV channels player built with Expo + React Native.

## Features
- Tamil channels from iptv-org
- Live streaming with expo-av
- Simple dark UI

## Run locally
```bash
npm install
npx expo start
```

## Build APK (GitHub Actions)
Push to main → Actions will build release APK.

Playlist: https://iptv-org.github.io/iptv/languages/tam.m3u
